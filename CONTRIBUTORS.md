# Contributors

My First Commit is created and maintained by
[Scott Densmore](https://github.com/scottdensmore).

Thank you to everyone who improves the project through code, documentation, design feedback, issue
reports, and review. The complete contribution history is available in GitHub's
[contributors view](https://github.com/scottdensmore/my-first-commit/graphs/contributors).

## Recognition

Human contributors whose work is merged are acknowledged through the Git history, release notes,
and GitHub's contributors view. Substantial ongoing contributions can be added to this file with the
contributor's preferred name and profile link.

To contribute, start with [CONTRIBUTING.md](CONTRIBUTING.md).
